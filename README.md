# Saurav Upreti

I'm a software engineer based in Adelaide, Australia, working mostly on the backend and increasingly on
systems built around LLMs. I'm doing a Master of AI and Machine Learning at Adelaide University, I build
backend systems at Renegade Insurance, and on the side I run [finduni.ai](https://finduni.ai) — an
AI-powered study-abroad platform for Nepali students — where I work across the whole stack (React, Supabase,
Vercel) and the AI features layered on top of it.

I started out in mobile development with Flutter, moved into backend engineering, and these days most of my
curiosity goes into making LLM systems reliable — agents, retrieval, evaluation, and the unglamorous
production plumbing that makes them actually work. A lot of what's on this profile is me learning that in the open.

### What I'm working on

- **[ctn-gitstashpop](https://github.com/upretisaurav/ctn-gitstashpop)** — my solo entry in UNSW's
  Capture the Narrative 2026, a research competition where AI agents compete for influence inside a sandboxed,
  simulated social network. Finished **7th of 168 teams** (47th after the first weekend). An autonomous Python
  agent on Render that writes with Claude, plus a Claude Code review loop that read its own logs and retuned it
  every four hours; the 67-entry `EXPERIMENTS.md` is the record of what worked and what didn't.
- **[finduni.ai](https://finduni.ai)** — AI mock-interview practice for students facing UK and Australian
  visa interviews: scored sessions, a credit system, and the production work around them. React, Supabase,
  Vercel, OpenAI.
- **[careerlens-mcp](https://github.com/upretisaurav/careerlens-mcp)** — an MCP server that gives Claude
  real-time career intelligence: salary benchmarks, live job listings, skill-demand analysis, and resume ATS
  scoring. Built with FastMCP + FastAPI + React.
- **[gemini-agent](https://github.com/upretisaurav/gemini-agent)** — a small autonomous agent on Google's
  Gemini with function calling that can read, write, and run files inside a sandboxed directory.
